# ノートの中の一覧(インラインビュー)

ノートの本文の中に、表・カンバン・カレンダー・リストの一覧を置けます。Notion のインラインデータベースと同じ考え方で、一覧に並ぶノートはそのノート専用のフォルダーに保存されます。

## 画面から使う

1. ノートを編集し、ツールバーの「一覧を挿入」(表のアイコン)を押す。
2. 名前(例:タスク)と表示(表・カンバン・カレンダー・リスト)を選んで「挿入」。
3. 「プレビュー」やノートのページで、一覧の上のタブを押すと表示を切り替えられます。切り替えた表示は保存されます。
4. 「+ 新規」で、一覧の中にノートを追加します。カンバンなら列(ステータス)、カレンダーなら日付も一緒に決められます。
5. ⚙(一覧の設定)で、名前・保存先のフォルダー・列にする項目・日付の項目を変えられます。

カンバンのカードは、PC ではドラッグで、スマホでは各カードの選択欄で別の列へ移せます。

## テキストで書く

一覧は、本文の中の次のブロックです。手で書いても、画面で作ったものを書き換えても構いません。

````markdown
```gmemo-view
name: タスク
type: kanban
folder: Projects/プロジェクトA/タスク
```
````

- `type`: `table`(表)/ `kanban`(カンバン)/ `calendar`(カレンダー)/ `list`(リスト)
- `folder`: 一覧に並べるノートのフォルダー。画面から作ると「このノートの名前のフォルダー/一覧の名前」になります。
- そのほか、独立したビュー(「ビュー」画面、`.views/*.yaml`)と同じ設定がすべて使えます: `groupBy`(カンバンの列にする項目、既定は `status`)、`dateProperty` / `endDateProperty`(カレンダー、既定は `date`)、`columns`、`filters`、`sort`、`tag` など。

ほかの Markdown ツール(GitHub、Obsidian など)では、このブロックは設定が書かれたコードとして表示されるだけです。

## 注意

- ノートの名前を変えても、一覧の `folder` は変わりません(中のノートはそのまま表示されます)。フォルダー名も揃えたいときは、設定でフォルダーを変えてください。
- 設定の YAML の書き方に誤りがあると、一覧の代わりにエラーと直し方が表示されます。画面から設定を変えても、壊れた YAML を上書きすることはありません。
- 過去の版を表示しているときは、一覧は表示のみです(タブや追加は使えません)。
