# 画面の基本方針(外部設計のベースライン)

このアプリの機能は、**画面(GUI)からも、テキスト(Markdown / YAML)からも操作できる**ようにします。新しい機能を作るとき、既存の機能を直すときは、この方針を前提にします。

## 方針

1. **GUIで操作できることを必須にする。** YAML や記法を知らなくても、ボタン・入力欄・選択肢だけで目的を果たせるようにします。
2. **テキストで直接書けることも残す。** 慣れた人にとっては、キーボードだけで書くほうが速く、ほかのツール(Git、エディタ、AIエージェント)とも同じ形式でやり取りできます。
3. **どちらも同じデータを変える。** GUIとテキストは、同じノートのテキストやビューの YAML を見る 2 つの窓です。片方で変えた内容は、もう片方にすぐ反映されます。GUI だけが持つ隠れた設定は作りません。
4. **GUI はテキストを壊さない。** GUI が書き換えるのは、その操作に関係する部分だけです(例: プロパティを変えても本文には触れない)。テキストの書き方に誤りがあるときは、推測で上書きせず、直し方を案内します。

## 新しい機能のチェック項目

プルリクエストでは次を確認します。

- テキスト(YAML・記法・設定ファイル)を書かないと使えない操作はないか。あれば、同じことができる GUI を用意したか。
- GUI で変えた内容が、テキスト側でもそのまま読める形で保存されるか。
- 画面の説明文が「〜を書いてください」だけになっていないか(GUI での操作方法を先に案内し、記法は補足にする)。

## 例外

- **サーバーの起動前に決まる設定**(公開 URL、シークレット、Cloudflare の設定など)は、デプロイ時の環境変数で設定します。アプリが動く前の値なので、画面からは変えられません。管理画面では現在の値を表示します。
- **新規登録の方法**(誰でも登録可 / 招待制 / 登録停止。`GMEMO_SIGNUP`)は、**意図的に画面から変えられないようにしています。** 誰がアカウントを作れるかはシステム全体の安全に直結するため、管理者のセッションが乗っ取られた場合でも、画面の操作ひとつで登録を開けないようにするためです。変えるときはデプロイ設定を変えて再デプロイします(デプロイには Cloudflare アカウントの権限が別に必要です)。管理画面では現在の値を表示します。

## 対応状況

| 機能                                                       | GUI                                                                            | テキスト                            | 状態                         |
| ---------------------------------------------------------- | ------------------------------------------------------------------------------ | ----------------------------------- | ---------------------------- |
| ノートのプロパティ(日付・終了・タグ・ステータス・任意項目) | 編集画面の「プロパティ」                                                       | ノート先頭の YAML                   | 対応                         |
| ノートごとの AI 送信範囲・機密ノート                       | 編集画面の「プロパティ」                                                       | `ai:` / `sensitivity:`              | 対応                         |
| ビュー(表・カンバン・カレンダー・リスト)                   | 「ビュー」のフォーム                                                           | `.views/*.yaml`(YAML タブ)          | 対応                         |
| フォルダごとの AI 送信範囲                                 | 設定 → AIポリシー                                                              | `.gmemo/policy.yaml`                | 対応                         |
| 見出し・箇条書き・チェックリスト                           | 編集画面のツールバー                                                           | Markdown                            | 対応                         |
| 書いた内容の確認                                           | 編集画面の「プレビュー」「並べて表示」                                         | Markdown                            | 対応                         |
| ノートへのリンク                                           | ツールバーのボタンからノートを検索して挿入(選択中の文字はリンクの表示名になる) | `[[ノート名]]`                      | 対応                         |
| カンバンでのステータス変更                                 | PC はカードを別の列へドラッグ、スマホは各カードの列の選択欄                    | `status:`(グループ化するプロパティ) | 対応                         |
| 新規登録の方法(誰でも/招待制/停止)                         | 管理画面は表示のみ                                                             | デプロイ設定 `GMEMO_SIGNUP`         | 意図的に対象外(上の「例外」) |
