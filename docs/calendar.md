# カレンダー連携

カレンダー型のビューは、Googleカレンダーなどの外部カレンダーと2つの方向で連携できます。どちらも設定画面の「カレンダー連携」から行います。

## 外部カレンダーを取り込む(Googleカレンダー → アプリ)

Googleカレンダーの予定を、アプリのカレンダービューに重ねて表示します。読み取りのみで、アプリから外へは何も送りません。

1. パソコンのブラウザで Googleカレンダーを開き、歯車 →「設定」
2. 「マイカレンダーの設定」から対象のカレンダーを選ぶ
3. 「カレンダーの統合」にある **「iCal 形式の非公開URL」** をコピーし、アプリの設定に貼り付ける

- 予定はサーバーが15〜30分ごとに取得します(「今すぐ更新」も可)。繰り返し予定、除外日、個別に変更された回、終日・複数日の予定に対応しています。
- 非公開URLはそれ自体が鍵です。サーバーのデータベースに保存されます(画面では一部を伏せて表示)。漏れた場合はGoogle側でURLをリセットしてください。
- 取り込めるカレンダーは1人20個まで、1つあたり約2MBまでです。
- 取り込んだ予定はAIには渡しません。
- Googleカレンダー以外でも、iCal(`.ics`)形式のURLなら使えます(`https://` のみ。`webcal://` は自動で読み替えます)。

## ノートの予定を公開する(アプリ → Googleカレンダー)

カレンダー型のビューを、購読用の `.ics` URLとして公開します。Googleカレンダーの「他のカレンダー」→「＋」→「URLで追加」に貼り付けると、ノートの予定がGoogleカレンダー(スマホのアプリを含む)に表示されます。

- 読み取りのみです。Google側の反映には数時間かかることがあります。
- URLにはランダムなトークンが入っていて、サーバーにはハッシュだけを保存します。URLは作成時に一度だけ表示され、不要になったら無効にできます。
- Googleがサーバーに取りに来るため、サーバーがインターネットから到達できる必要があります。

### 外に出る情報

予定のタイトルと日時、オプションでノートへのリンク(リンクにはノートのパスが含まれます)だけです。本文は出ません。さらに:

- AIポリシーで **「外部AI可」** のフォルダにあるノートだけが含まれます
- `sensitivity: secret` や `ai: local` / `ai: none` のノートは含まれません
- 機密情報(APIキー、辞書に登録した語など)が検出されたタイトルは「予定」に置き換わります

## ノートの日付の書き方

```yaml
---
date: 2026-10-12 # 終日
---
```

```yaml
---
date: 2026-10-12 10:00 # 時刻つき(GMEMO_TIMEZONE で解釈)。終了がなければ1時間
end: 2026-10-12 11:30 # 終了(任意)
---
```

終了日のプロパティは、ビューの `endDateProperty` で指定します。終日の終了日は「その日を含む」意味です(`date: 2026-10-24`, `end: 2026-10-25` は2日間)。

```yaml
# .views/schedule.yaml
name: 予定
type: calendar
folder: 予定
dateProperty: date
endDateProperty: end
```

スマホでは、カレンダービューは「これから2週間」の予定一覧(ノートと外部カレンダーをまとめて時刻順)と、ノートのリストで表示されます。
