# 利用上の注意

## 機密情報の検出は補助です

このアプリは、外部AIへ送る前とノートの保存時に、ローカルで機密情報らしきものを検出します(APIキー、トークン、秘密鍵、パスワードらしき文字列、クレジットカード番号、マイナンバー、電話番号、メールアドレス、登録した辞書の語、任意でローカルLLMによる人名・住所・社名など)。検査のためにデータを外部へ送ることはありません。

**ただし、検出は補助であり完全ではありません。** 書式が想定と違う、文脈でしか機密とわからない、といった情報は見逃します。逆に、関係のない数字列を誤検知することもあります。

機密情報は、まず**フォルダ単位の送信制御**で守ってください。

- 外部AIに渡してよいフォルダだけを「外部AI可」にする(初期値は「ローカルLLMのみ」)
- 機密を扱うフォルダは「ローカルLLMのみ」または「AI不可」にする
- 個別のノートには `sensitivity: secret`(自動でローカルLLMのみ)や `ai: none` を付ける

初めて外部AIを有効にするときにも、画面に同じ注意が表示されます。

## 外部AIへ送られるもの

外部AI(Anthropic、OpenAIなど)へデータが出るのは次の場合だけです。

1. 「ノートに質問」で外部AIを使ったとき:質問文と、関連ノートのうち「外部AI可」のものの一部
2. MCP/REST で接続した外部エージェントがノートを読んだとき:そのエージェントが見られる「外部AI可」のノート

どちらも、検出された機密情報は設定に応じて警告・マスキング・ブロックされます。外部への送信は設定画面の「AI送信ログ」で確認できます(送った内容そのものは記録しません)。

## 自分で管理するデータ

- サーバーとデータはあなたの管理下にあります。ディスク暗号化とバックアップはあなたが行ってください。
- `notes/` フォルダはただのGitリポジトリです。リモート(GitHubなど)へpushすると、そのサービスにノートの全履歴が渡ることに注意してください。
- アカウント情報はユーザー名とパスキーの公開鍵だけです。メールアドレス、本名、IPアドレスのログは持ちません(リバースプロキシのアクセスログは、プロキシ側の設定で別途無効にしてください。同梱のCaddy設定ではオフです)。

## AIの書き込み

- AIの変更は原則として提案になり、あなたが承認するまでノートには入りません。
- 自動マージや直接書き込みを許可したエージェントの変更は、承認なしで入ります。履歴画面からいつでもまとめて取り消せます。
- AIが書いた段落は色分け表示されます。内容の正しさはAIの出力であることを踏まえて確認してください。
